## Documentation conventions

- **Implemented** means verified in the current source code and runnable or testable.
- **In progress** means some code exists but the complete behavior is not verified.
- **Planned** means design intent only.
- **Verify in code** means this document does not yet have enough evidence to state the detail as fact.
